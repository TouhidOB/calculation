What is Base Conversion?

Base conversion is the process of changing a number from one positional numeral system (radix) to another. While we use the Decimal system (Base 10) in everyday life, computer systems rely heavily on Binary (Base 2), Hexadecimal (Base 16), and Octal (Base 8).

Common Number Systems Explained

Radix / Base Name Digits Used Primary Use
Base 2 Binary 0, 1 Machine code, logic gates, digital circuits
Base 8 Octal 0 - 7 Unix file permissions, legacy computing
Base 10 Decimal 0 - 9 Standard human arithmetic
Base 16 Hexadecimal 0 - 9, A - F Web colors, memory addresses, Unicode

How Conversion Works

All these systems are "positional," meaning the value of a digit depends on its position in the number.

For example, in the decimal number 153:

(1 × 10²) + (5 × 10¹) + (3 × 10⁰) = 100 + 50 + 3 = 153

In Binary 101, the same logic applies using powers of 2:

(1 × 2²) + (0 × 2¹) + (1 × 2⁰) = 4 + 0 + 1 = 5 (in Decimal)

What Is a Number Base?

A number base, or radix, defines how many unique digits a system uses before rolling over. Decimal uses ten digits (0-9), binary uses two (0-1), octal eight, and hexadecimal sixteen. Each position represents a power of the base — the foundation of every conversion calculation. In binary, 1011 means (1×8)+(0×4)+(1×2)+(1×1) = 11 decimal.

How Do You Convert Decimal to Binary by Hand?

Divide the number by 2 repeatedly and record each remainder; reading the remainders bottom-to-top gives binary. For 45: remainders are 1,0,1,1,0,1 → 101101. This repeated-division method works for any base — divide by that base instead. The calculator automates this tedious calculation.

Why Do Programmers Use Hexadecimal?

One hex digit maps cleanly to exactly four binary digits, making long binary strings readable. The value 11111111 (255 decimal) becomes just FF — two characters instead of eight. This compactness is why hex appears in memory addresses, color codes like #FF5733, and assembly debugging.

Frequently Asked Questions

Why does hexadecimal use letters?

Hexadecimal needs 16 digits, but decimal only provides ten symbols (0-9). The letters A-F fill the gap, representing values 10 through 15, letting one character express any four-bit group.

What is the difference between octal and hexadecimal?

Octal (base 8) groups binary into three-bit chunks; hexadecimal (base 16) groups into four-bit chunks. Hex is more common in modern computing because it aligns with byte boundaries.
