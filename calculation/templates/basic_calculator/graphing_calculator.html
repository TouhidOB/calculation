What Does a Graphing Calculator Do?

It plots the relationship between a function's input (x) and output (y), drawing a curve that shows behavior at a glance. Instead of computing single points, it evaluates the function across a whole range, turning calculation into a visual picture. This exposes maximums, minimums, intercepts, asymptotes, and periodic patterns that raw numbers hide.

How Do You Plot a Function?

Type the equation, set the x and y range for the viewing window, and the calculator evaluates the expression at many points to draw a smooth curve. The Math.js engine handles the underlying calculation, computing y for a dense set of x-values and connecting them. Adjusting the window zooms in on details or pulls back for the overall shape.

What Functions Can You Graph?

The calculator graphs linear (2x+3), polynomial (x³−4x), trigonometric (sin(x), cos(x)), exponential (eˣ), and combined functions like sin(x)·x². Because it's powered by Math.js, it interprets standard mathematical syntax and evaluates each function type with precision — useful from early algebra through calculus.

Frequently Asked Questions

How do I set the viewing window?

Define the minimum and maximum for both axes. Wider ranges show overall shape; narrower ranges reveal local detail like intercepts and turning points.

Do I need a physical graphing calculator?

No. This online tool replicates the core plotting power of a hardware device in your browser, for free, handling the same function types.

Why is my graph not showing?

Usually the function's values fall outside the current window. Widen the y-range, and check the syntax — Math.js expects forms like x^2 and sin(x).
