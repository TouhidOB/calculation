Matrices power computer graphics, physics simulations, and systems of equations — but their arithmetic follows rules that trip up beginners, especially multiplication and the determinant. Key Takeaways
  • A 2×2 matrix has four entries arranged in two rows and two columns.
  • Addition and subtraction work entry by entry.
  • Multiplication combines rows with columns — it is not entry-by-entry.
  • The determinant of [[a,b],[c,d]] is ad − bc.

What Is a Matrix?

A matrix is a rectangular array of numbers arranged in rows and columns. A 2×2 matrix holds four values and is the simplest non-trivial case. Matrices represent transformations, systems of linear equations, and data tables. Operating on them correctly requires following specific rules — exactly what the calculator automates in every calculation.

How Does Matrix Multiplication Work?

Unlike addition, matrix multiplication combines each row of the first matrix with each column of the second, summing the products. For 2×2 matrices, each result entry is a sum of two products. This row-by-column rule is where hand calculation most often goes wrong — the calculator applies it precisely every time.

What Is a Determinant?

The determinant is a single number summarizing key properties of a square matrix. For a 2×2 matrix [[a, b], [c, d]], it equals ad − bc. A nonzero determinant means the matrix is invertible and its transformation preserves area; a zero determinant means it collapses space. The calculator computes it instantly.

Frequently Asked Questions

How do you add two matrices?

Add corresponding entries: top-left to top-left, and so on. Both matrices must be the same size. The calculator does this entry-by-entry automatically.

Is matrix multiplication commutative?

No. In general, A×B does not equal B×A. Order matters in matrix multiplication, unlike ordinary number multiplication.

What does a determinant of zero mean?

The matrix is singular — it has no inverse, and its transformation flattens space onto a line or point. Systems using it may have no unique solution.
