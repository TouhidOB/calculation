What Is a Truth Table?

A truth table is a chart that shows the output of a logical expression for every possible combination of its inputs, where each variable is either true (1) or false (0). It fully defines the behavior of a boolean formula, leaving no case untested. Truth tables are foundational to digital logic, programming conditions, and formal reasoning calculation.

Frequently Asked Questions

What is XOR?

Exclusive OR — true only when the two inputs differ. A XOR B is true for (true, false) and (false, true), but false when both match.

How many rows will my table have?

2ⁿ, where n is the number of distinct variables. Three variables give 8 rows, four give 16. The generator builds them all automatically.

What are truth tables used for?

Designing digital circuits, simplifying logic, verifying programming conditions, and teaching boolean algebra all rely on truth tables.
